Supabase Database Setup

If real-time database messages are not saving or showing an error, ensure your Supabase database table messages is created.

Run the following SQL script in your Supabase SQL Editor :

CREATE TABLE public.messages (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    username VARCHAR NOT NULL,
    user_color VARCHAR DEFAULT '#6366f1',
    content TEXT NOT NULL,
    room VARCHAR DEFAULT 'general' NOT NULL
);

-- Enable Row Level Security (RLS)
ALTER TABLE public.messages ENABLE ROW LEVEL SECURITY;

-- Allow public read & write access
CREATE POLICY "Allow public read access" ON public.messages FOR SELECT USING (true);
CREATE POLICY "Allow public insert access" ON public.messages FOR INSERT WITH CHECK (true);

-- Enable Realtime for messages table
ALTER PUBLICATION supabase_realtime ADD TABLE public.messages;
